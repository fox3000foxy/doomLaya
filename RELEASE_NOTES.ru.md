# Примечания к выпуску (перевод)

[English](RELEASE_NOTES.md) · Русский — перевод файла RELEASE_NOTES.md.
Оригинал на английском используется как текст GitHub Release.

Решения в Doom принадлежат моделям: Laya и Jev выбирают действие, цель и оружие;
общий моторный контроллер исполняет этот выбор.

Выпуск включает чекпоинт Doom-адаптированной Laya v3 и параллельные видео.
На FreeDoom MAP01, skill 3, seed 48: исходная Laya не уложилась в 180 секунд;
адаптированная Laya дошла до MAP02 за 61,429 секунды; Jev — за 68,971 секунды.
Оба финишировавших выжили. Laya дообучалась под эту задачу; Jev — нет.
Одна карта и один итоговый seed не доказывают общего превосходства модели.

Медиана HTTP с учётом RTT: адаптированная Laya 108 мс, Jev 357 мс.
Стоимость API Jev за финальный прогон: $0,004580184. Локальные вычисления не оценивались.
Инструкции по обучению и зафиксированные датасеты входят в исходный репозиторий.

Архив модели содержит Apache-2.0, атрибуцию, карточку модели и SHA256SUMS.
Проверьте laya-doom-v3.tar.sha256 перед распаковкой архива в checkpoints/.

Модель: https://huggingface.co/azalio/laya-doom-v3
Руководство по обучению: https://github.com/azalio/doomLaya/blob/main/docs/TRAINING.md
